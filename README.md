# Telegram News Bot

Бесплатная RSS-подборка новостей о войне России и Украины для Telegram-канала. Запуск по GitHub Actions каждые 10 минут (возможны задержки). Один материал = отдельное изображение + подпись со ссылкой на первоисточник.

**Важно:** программа **не проверяет факты независимо**. Она собирает заголовки из Google News RSS и допускает сообщения выбранных редакций, в том числе заявления сторон и неподтвержденные сведения, явно помеченные как непроверенные. Не называйте эту систему «проверкой фактов». Нельзя использовать как источник точных оперативных данных. Не добавляйте секреты в публичные файлы.

## Настройка Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather). Сохраните токен **вне публичного репозитория**.
2. Добавьте бота администратором канала, разрешите **публикацию сообщений**.
3. Откройте **Settings → Secrets and variables → Actions → New repository secret**.
4. Создайте секрет **TELEGRAM_BOT_TOKEN** — токен из BotFather.
5. Создайте секрет **TELEGRAM_CHAT_ID** — публичный адрес канала в формате **@my_channel** (если канал публичный). Для приватного канала нужен числовой ID вида -100...; не подставляйте ссылку-приглашение.
6. В **Settings → Actions → General → Workflow permissions** разрешите **Read and write permissions** для сохранения списка опубликованных материалов в state.json. Если настройка недоступна, обратитесь к владельцу репозитория.

## Проверка

Вкладка **Actions → Telegram news (every 30 minutes) → Run workflow**. По умолчанию **dry_run = true**: бот проверяет ленты, но не публикует. Смотрите лог **Run bot**.

Когда убедитесь, что новости подходят, запустите вручную с **dry_run = false**. Расписание работает автоматически после добавления секретов. Если пока не хотите автопубликаций, временно отключите workflow во вкладке Actions.

## Как работает

- Используются Google News RSS запросы по темам. Google News — агрегатор, а не независимый проверяющий факты.
- Публикуются **заголовки** с датой, ссылкой на публикацию, названием источника и пометкой о статусе. Программа **не придумывает текст статьи** и не заявляет, что прочитала её.
- Выбираются публикации возрастом **1–8 часов**: это снижает риск распространения сообщений прямо во время события, но не гарантирует безопасность.
- Есть простая фильтрация очевидных координат и некоторых тактических выражений; она **не гарантирует** исключение опасной информации. При сомнении выключите автопубликацию.
- Изображение: иллюстративное фото с Wikimedia Commons (если найдено с допустимой лицензией) или **собственная графическая карточка**. Архивное фото всегда подписано как иллюстрация, не фотография события. Проверьте условия лицензий при использовании Commons.
- Не более **3 постов за запуск** и **50 в сутки**. Список опубликованных ID хранится в state.json и обновляется в репозитории.
- Без платного API. Публичный репозиторий и стандартные GitHub-hosted runners обычно не расходуют платные минуты; учитывайте правила и лимиты GitHub.

## Возможные ограничения

- Нет гарантии, что RSS всегда доступен и каждые 30 минут появятся подходящие новости.
- Автоматическое сопоставление разных сообщений и настоящая фактологическая проверка **не реализованы**. Это стартовый агрегатор, а не полноценная редакционная система.
- Поиск фото через Wikimedia Commons может не дать результата; тогда будет собственная карточка.
- Запланированные задания GitHub Actions могут задерживаться или отключаться при длительной неактивности репозитория.
- Если несколько запланированных запусков начнутся почти одновременно, действует concurrency. Не запускайте несколько ручных публикаций одновременно.
- GitHub Actions хранит историю запусков и логи: не выводите туда токен бота.

## Локальная проверка

\`\`\`bash
pip install -r requirements.txt
DRY_RUN=1 python bot.py
\`\`\`

Для отправки нужны переменные окружения TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID.

## Расширенный мониторинг

- Проверки каждые **10 минут** (по возможности GitHub Actions).
- **10 поисковых подборок** Google News на русском и английском, редакции из России, Украины и других стран. Это не гарантирует охват всех источников.
- До **3 публикаций за проверку**, до **50 в сутки**; если новостей нет, постов нет.
- Публикации по-прежнему не являются независимым подтверждением фактов; возможны дубли разных редакций и ошибки автоматической классификации.


## Улучшения качества (версия 2)

- **news_quality.py**: отдельные правила отбора. Консервативное сравнение заголовков разных редакций, фильтрация очевидных оперативных деталей, проверка HTTPS-ссылок, более точная проверка названий источников.
- **Разнообразие**: при выборе постов предпочитаются разные источники и темы. Один источник ограничен восемью публикациями за день.
- **История**: для новых публикаций сохраняются название, редакция и тема, чтобы снижать число повторов в течение суток. Старые записи без заголовков сохраняются совместимыми.
- **Изображения**: Wikimedia Commons — только CC0/Public Domain с явной подписью, либо собственная новостная карточка. Изображения не являются документальным подтверждением события.
- **Автотесты**: перед публикацией GitHub Actions проверяет синтаксис и запускает Python unittest. При ошибке тестов публикация не начинается.
- **Ограничения**: эвристики не могут достоверно установить истинность новости, определить все дубли между языками или обнаружить все опасные сведения. Источники могут публиковать ошибки и неподтвержденные сообщения. Автоматический режим требует редакционного контроля.
- **Тест после обновления**: Actions → Telegram news (every 10 minutes) → Run workflow → dry_run=true. Убедитесь, что шаги Validate Python syntax и Run quality tests зелёные, затем проверьте Run bot.


## Расширение источников

- В список распознаваемых редакций добавлены российские федеральные и региональные газеты и агентства, независимые русскоязычные редакции, украинские и международные СМИ (свыше 170 названий/вариантов написания).
- Поиск Google News расширен с 10 до 16 RSS-запросов, в том числе тематическими запросами по доменам нескольких редакций. Прямая лента «Медузы» сохранена.
- Это **не прямое подключение ко всем перечисленным сайтам**. Новость появится только если доступна в выбранных RSS-подборках, проходит фильтры и не дублирует уже опубликованную.
- Издание в списке не означает, что его сообщения независимо проверены. Отбор редакций не означает поддержку их позиции.
- Для расширения перечня используйте массив PUBLISHERS, а для обнаружения материалов — QUERIES в bot.py. Слишком много запросов могут замедлить запуск и вызвать ограничения сервиса.
